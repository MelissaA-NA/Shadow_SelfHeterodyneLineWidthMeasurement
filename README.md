## Self Heterodyne Python Script
See [Laser Linewidth Measurements](https://nomadatomics.atlassian.net/wiki/spaces/KB/pages/385646594/Laser+Linewidth+Measurements) for information how to work with this script.

This script enables the user to determine the correct linewidth of a laser measured with a selfheterodyne setup. The beta seperation line method is used to get the linewidth and left over coherence between beam paths is corrected.
